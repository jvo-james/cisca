The working sequence

From clean skin to final spray.

  1. Cleanse
  2. Tone if needed
  3. Base moisturiser
  4. Moisturise face and under-eye
  5. Prime T-zone and skin type needs
  6. Foundation
  7. Contour
  8. Blush
  9. Concealer / highlight
  10. Set highlights
  11. Set whole face
  12. Hydrating setting mist
  13. Bake
  14. Powder contour and blush
  15. Eyeshadow and liner
  16. Lips
  17. Eyelashes
  18. Setting spray
  19. Finishing touches
Classroom note

Practice the reason, not just the step.

Skin types, undertones, face structure, product texture and the finish you are aiming for all change how the same technique should be used. Treat this guide as a map, then use supervised practice to understand the choices inside each step.
