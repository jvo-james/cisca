Availability behavior
---------------------
The public availability endpoint now supports a month view. It returns only:
- closed dates
- anonymous busy time ranges

It never exposes booking names, email addresses, phone numbers or notes.

The server also checks the selected date/time again immediately before creating the pending booking and Paystack payment session.

The six appointment start times shown in booking.js are configured in TIME_SLOTS:
09:00, 10:30, 12:00, 13:30, 15:00, 16:30

If Cisca later wants different operating hours, edit only that TIME_SLOTS array.
